# DataWrangling Modules

This repository contains a library of [DataWrangling](https://github.com/NumericalEarth/NumericalEarth.jl/tree/main/src/DataWrangling) modules to initialize and force [NumericalEarth.jl](https://numericalearth.github.io/NumericalEarthDocumentation/dev/). Eventually these modules will merged with NumericalEarth.jl. 


## Datasets 

Below is a list of datasets we will be building modules for. These are loosely separated into "high" and "low" priority.

### High priority
- [ ] [GLODAPv2.2016b_MappedClimatologies](https://glodap.info/index.php/mapped-data-product/)
- [ ] [Mauna Loa CO2 Record](https://scrippsco2.ucsd.edu/data/primary-mauna-loa-co2-record/)

### Low priority
- [ ] [NOAA Marine Boundary Layer Reference (surface CO2)](https://gml.noaa.gov/ccgg/mbl/) 
- [ ] [CCMP Wind Speed](https://podaac.jpl.nasa.gov/dataset/CCMP_WINDS_10M6HR_L4_V3.1)
- [ ] [Japanese Reanalysis for Three Quarters of a Century
(JRA-3Q)](https://www.data.jma.go.jp/jra/html/JRA-3Q/index_en.html)

Note: some datasets may be easier to download from the [NCAR GDEX THREDDS Server
NCAR GDEX THREDDS Server](https://tds.gdex.ucar.edu/thredds/catalog/catalog.html)
